## 2. 문자열 단정 — 눈으로 보기 전에 돌린다

```bash
# muted 교정 확인 — 0건이어야 한다
grep -rn '71717a' src/ tailwind.config.ts

# 선택 상태에 accent가 남아 있는지 — 제출·참여 버튼만 걸려야 한다
grep -rn 'bg-accent\b' src/

# 폰트 클래스 px를 가로 패딩과 구분해 센다
grep -rnE 'className=.*(^|[" ])px([" ]|$)' src/components/

# 레이아웃
grep -n 'max-w' src/components/layout/AppShell.tsx
grep -n 'GalmuriMono' src/app/globals.css src/components/feed/CliFooter.tsx

# aside prop이 완전히 사라졌는지
grep -rn 'aside' src/components/feed/RealtimeFeed.tsx src/app/dashboard/page.tsx
```

기대값:

| 명령 | 기대 |
| :--- | :--- |
| `71717a` | 0건 |
| `bg-accent\b` | 제출·참여 버튼과 `✓` 칩만. 탭·세그먼트·카드·정렬 칩은 0건 |
| `px` 폰트 클래스 | 액센트 버튼·탭·숫자 뱃지에 있고 한글 문구 칩·`결과물 ↗`에는 없다 |
| `max-w` | `AppShell.tsx`에 1건 |
| `GalmuriMono` | `globals.css`의 `@font-face`와 `CliFooter.tsx` 양쪽 |
| `aside` | 0건 |

## 4. 반응형 (`SC-008`)

브라우저를 375px로 좁힌다.

- 사이드바가 위로 접히고 본문이 1열이 된다.
- 가로 스크롤이 생기지 않는다.
- 아카이브와 랭킹이 세로로 쌓인다.
- 카드 CTA가 여전히 카드 바닥에 있다.

**`min-width:1280px`를 넣지 않았는지 여기서 걸린다.** 가로 스크롤이 생기면 L2 위반이다.

## 5. 참여자 정렬 (`TC-DETAIL-01`)

디자인과 무관한 도메인 수정이다. 자동 테스트가 덮지만 눈으로도 본다.

1. 스터디를 하나 만들고 다른 페르소나 2~3명으로 참여한다.
2. 상세 모달을 **여러 번 열고 닫는다.**
3. 참여자 순서가 매번 같고 **리더가 항상 첫 줄**이어야 한다.

행이 적으면 삽입 순서로 나와 버그가 숨는다. 순서가 흔들리면 `ORDER BY`가 빠진 것이다.
